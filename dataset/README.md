# Dataset Configuration
You can download dataset used for this project from this [link](https://www.kaggle.com/datasets/kaggleashwin/vehicle-type-recognition). The standard directory layout should look like this:

```bash
dataset/
├── train/
│   ├── bus/
│   ├── car/
│   ├── motorcycle/
│   └── truck/
├── test/
│   ├── bus/
│   ├── car/
│   ├── motorcycle/
│   └── truck/
```
